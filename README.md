# Lino

Finanzas personales para Android con estilo Cupertino y glassmorfismo: cuentas
de varios bancos, tarjetas de crédito, efectivo, ahorro con tasa fija, presupuesto
semanal (lunes a domingo, financiado por el sueldo del domingo) y un simulador que
recomienda cuándo y con qué pagar una compra. Todo se guarda cifrado y solo en el
teléfono.

## Empezar

1. Abre esta carpeta en VS Code (extensión Flutter instalada).
2. `Terminal > Ejecutar tarea... > Lino: preparar proyecto` (solo la primera vez).
3. Conecta tu teléfono o un emulador y presiona F5.

Comandos útiles: `flutter analyze`, `flutter test`, `flutter run`.

La planeación completa, las reglas de negocio y los siguientes pasos están en
[`docs/PLAN.md`](docs/PLAN.md). Las reglas para asistentes de código (chat de VS
Code, Copilot, Claude) están en [`AGENTS.md`](AGENTS.md).
